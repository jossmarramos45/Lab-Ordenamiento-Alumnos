# Lab-Ordenamiento-Alumnos

Laboratorio de programación en Java donde se implementan algoritmos de ordenamiento
aplicados a un arreglo de objetos de tipo Alumno.

## Objetivo
Implementar y aplicar los algoritmos de ordenamiento Burbuja, Selección e Inserción
para ordenar arreglos de alumnos, comparando por código y por nombre.

## Contenido
- Clase Alumno (atributos: codigo y nombre)
- Ordenamiento Burbuja
- Ordenamiento por Selección
- Ordenamiento por Inserción
- Ordenamiento por código
- Ordenamiento por nombre
- Pruebas unitarias con JUnit

## Estructura del proyecto
- src/: código fuente del proyecto
- test/: pruebas unitarias (JUnit)

## Ejecución
Ejecutar la clase `LaboratorioAlumno` para ver el arreglo antes y después del ordenamiento.
